# Glasskit

**Glasskit** is a lightweight, accessible and customizable UI system based on glassmorphism design principles.
Built with HTML, CSS and JavaScript, it focuses on performance, semantic structure and a refined visual experience.

---

## Overview

Glasskit is the foundation of a design system intended to power a personal portfolio.

Rather than being just a layout, it explores how visual style, semantic HTML and interaction patterns can work together to create a cohesive UI layer.

---

## Goals

* Build a reusable UI system based on glassmorphism
* Maintain strong semantic HTML structure
* Ensure accessibility and usability
* Keep performance as a first-class concern
* Serve as a foundation for a personal portfolio

---

## Current Features

### Layout

* Responsive layout with `header`, `aside` and `main`
* `main` with fixed heigh and scrollable content
* Glass-style card containers

### Typography, Content & Semantics

* Full heading scale (`h1`–`h6`)
* Paragraphs, lead text and inline elements
* Rich text formatting (`strong`, `em`, `mark`, etc.)
* Semantic elements (`abbr`, `cite`, `dfn`, `time`, `blockquote`)
* Lists (`ul`, `ol`)
* Code blocks (`pre`, `code`)
* Inline technical elements (`kbd`, `samp`, `sub`, `sup`)
* Interactive HTML elements (`details`, `summary`)

### Basic Contact Forms

* Accessible form structure
* Input validation
* Anti-spam field
* Prepared for API integration

### UI Elements

* Theme toggle (light/dark)
* Navigation menu
* Social links section
* Scroll controls (prev / next)
